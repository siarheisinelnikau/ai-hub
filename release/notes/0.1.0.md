First public release of ai-hub, a self-hosted control panel for a single AI server.

### Included

- Model lifecycle controls, GPU telemetry, model downloads, an authenticated OpenAI-compatible proxy, and seven media MCP tools.
- English installation and operations guides, MIT license, model illustrations, and real measurements from a 4 x RTX 3090 server. Documentation screenshots use separate preview data.
- All seven reviewed Dependabot updates (#1–#7), with GitHub Actions pinned to full commit SHAs and read-only repository permissions.
- Consistent version and Git revision reporting in both binaries and health endpoints.

### Install on Linux x86-64

Download the release archive and SHA256SUMS.txt into the same directory:

```sh
sha256sum -c SHA256SUMS.txt
tar -xzf ai-hub-v0.1.0-linux-amd64.tar.gz
cd ai-hub-v0.1.0
./aihub --version
./aihub
```

The first launch listens on localhost and generates a private login token in the token file. See README.md for model setup, configuration, and systemd deployment. The bundle includes the UI, source, and both static Linux binaries; model engines and weights are installed separately.

### Validation

Linux and Windows CI passed on commit 4a28942290173e818c8d2b9148847bb9b252d585, including the full test gate, 73/73 API parity checks, Linux race detection, Go vulnerability scanning, and secret scanning. Public history and release contents were reviewed for private data.

Upstream GitHub Actions still contain transitive dependency advisories. Their use was reviewed against this restricted CI workflow; they are not installed on the inference server. Scans do not establish the absence of all unknown vulnerabilities.
